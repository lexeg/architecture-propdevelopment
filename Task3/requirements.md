# Список требований, которым должны удовлетворить внешние интеграции

## Требования к безопасности
- Персональные данные должны передаваться и храниться в соответствии с ФЗ-152
- Партнерский сервис должен получать только минимальную информацию, которая необходима ему для выполнения операции
- Данные должны передаваться в зашифрованном виде
- Настроить лимиты на запросы (Rate Limiting)
- Добавить мониторинг
- Добавить журналирование

## Протоколы аутентификации и авторизации
Использовать OAuth 2.0 + PKCE. JWT-токен будет использоваться для работы с API внешнего сервиса

## Взаимодействие между системами предприятия и внешней платформой
1. Пользователь с помощью мобильного приложения запрашивает видео
2. tenant-core-app устанавливает соединение с сервисом партнера и запрашивает токен
3. Полученный токен tenant-core-app передает мобильному приложению клиента
4. Клиент с помощью токена получает видеопоток
5. При истечении сессии токена происходит обновление токена с помощью tenant-core-app
